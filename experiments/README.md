# 실험 기록

논문(UCWIT 2026) 실험 가운데 2026-11-08~11-12에 돌린 세 실험의 도구와 결과 요약을 둡니다. 질문, 조건, 결과 표, 실행 순서, 한계는 실험 폴더마다 있는 README에 적었습니다.

| 폴더 | 내용 |
|---|---|
| `eval_jev_raw_2026-11-08` | 상황 태그 대신 가공한 카메라 숫자와 터치 값을 Jev에 주고 지원을 고르게 한 실험 |
| `eval_llm_2026-11-09` | Jev가 받은 창별 입력을 GPT 모델 3개와 Claude 모델 2개에 그대로 주고 규칙표 · Jev와 비교한 실험. AI 담당의 시나리오 세트 3개에 모델을 더 돌린 실행 포함 |
| `eval_llm_2026-11-12_rA` | 상황 태그가 붙는 입력(값 묶음 b0_rA)으로 같은 비교를 다시 돌린 확인 실험. 논문 표에는 쓰지 않음 |

## 용어

- 창: 판단을 한 번 하는 시간 구간.
- 평가 사례: 장면과 터치 조건의 조합. 도움 사례 67건과 대기 사례 70건, 모두 137건입니다. 사례 창은 평가 사례에 속한 창입니다.
- 라벨 v5: 사례마다 허용 행동을 규정한 잠정 라벨.
- 지정 지원: 라벨이 그 사례에 맞다고 정한 지원. 지정 지원 재현율은 논문의 적합 기능 제공률입니다.
- 값 묶음: 상황 태그 규칙의 기준값 파일(`b0_r0`, `b0_rA`).
- 파일 이름과 도구 주석의 E3은 규칙표를 평가한 실험(작업 폴더의 `eval_ab_2026-11-04`, 라벨 v5와 값 묶음이 여기 있음), E5는 앞선 Jev 실험(`eval_jev_2026-11-04`), E12는 `eval_jev_raw_2026-11-08`입니다. E5_C0와 E5_J는 앞선 Jev 실험의 두 조건(후보 내, 후보 제한 없음)의 입력입니다.

## 저장소에 넣지 않은 것

- 실행 기록(모델별 답과 호출 기록), 창별 입력과 라벨, 모델 답 캐시는 비전 담당 작업 폴더에 있습니다.
- 촬영 영상과 프레임은 저장소에 넣지 않습니다.

## 실행할 때

- 도구는 비전 담당 작업 폴더의 배치를 기준으로 경로를 잡고, 앞선 Jev 실험(2026-11-04~05)의 실행기 · 채점기와 평가 키트의 채점기를 불러 씁니다. 그래서 저장소 안에서 바로 실행되지는 않습니다.
- `time_rule_table.py`와 `build_kit_2026-11-08.py`는 작업 폴더 위치를 환경 변수 `KIOSK_WORKSPACE`로 받습니다.
