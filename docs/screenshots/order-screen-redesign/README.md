# 주문 화면 변경 스크린샷

2026-11-15 Edge headless에서 CSS 뷰포트 1080×1920, 브라우저 확대율 100%로 촬영했습니다. 움직임 줄이기를 적용해 애니메이션을 멈춘 상태입니다. 배포 미리보기에서 샘플 상품 17개의 고정 API 응답을 사용했습니다. `support-offer.png`와 `large-view.png`는 제안 카드가 아직 특징 전송 응답에 연결되지 않아 개발 샘플 서버에서 촬영했습니다. `complete.png`는 2026-11-16에 같은 조건으로 다시 촬영했고, 고정 응답의 주문번호는 개발 샘플의 첫 번호 `DEMO-001`입니다. `option-sheet.png`는 2026-11-17에 온도 버튼과 수량 조절의 열 맞춤을 반영해 개발 샘플 서버에서 같은 뷰포트와 확대율로 다시 촬영했습니다.
