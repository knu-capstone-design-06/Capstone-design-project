# PR #70 화면과 PR #79 자동 읽기 통합 검증

2026-11-20, #70을 일반 merge로 병합한 main `9317b0b`를 TTS 브랜치에 반영한 상태를 검증했습니다. 세 이미지 모두 Edge headless, 1080×1920, deviceScaleFactor 1입니다. 실제 G10의 Windows 배율·브라우저 F11 검증과 구분합니다.

- [기본 화면 안내 읽기](default-tts.png)
- [큰 글씨·큰 버튼·낮은 화면 안내 읽기](large-low-tts.png)
- [큰 글씨의 중단 버튼 가림 수정 후](large-text-tts.png): 고정 HTTP 응답·모의 인식·합성으로 별도 검사한 화면입니다.

프론트 Vite `/backend/` 프록시를 실제 로컬 FastAPI 서버에 연결했습니다. 저장소의 메모리 주문 저장소와 음성 서비스·도구 실행을 사용했습니다. 외부 OpenAI HTTP 응답만 HTTPX MockTransport로 고정하고, 브라우저 음성 인식·합성은 모의 객체를 사용했습니다. 외부 API·실제 마이크·스피커·PostgreSQL은 이 검사에서 사용하지 않았습니다. 검증용 서버와 스크립트는 임시 폴더에서 실행했으며 제품 코드·서버 설정을 바꾸지 않았습니다.

기본 화면과 확대·낮은 화면 각각에서 다음 흐름을 확인했습니다.

1. 터치로 아이스 아메리카노 1잔을 담아 서버 Cart를 확인합니다.
2. 음성 요청으로 1잔 추가 확인 질문을 받고 자동으로 읽습니다. 수락 전 서버 수량은 1로 유지됩니다.
3. 안내 시작 시 [안내 중단]이 보이고 다른 요소에 가리지 않는지 검사합니다. 확대·낮은 화면은 내부 영역이 버튼 위치로 스크롤됩니다.
4. 안내 종료 후 399ms 이상을 기다린 뒤 마이크가 다시 열립니다. 모의 인식·합성의 동시 실행은 없습니다.
5. “네” 응답 뒤 실제 backend가 Cart를 변경하고 프론트가 재조회합니다. 수량 2를 확인합니다.
6. [주문 확인] → [주문하기]로 서버의 모의 주문번호를 표시하고, [새 주문 시작]으로 새 서버 세션을 만듭니다.

프론트 단위 테스트 158개, `voiceWait.integration.test.mjs` 6개, TypeScript·Vite 빌드가 통과했습니다. 백엔드는 일반 테스트 27개와 모듈 테스트 164개가 통과했으며, PostgreSQL 테스트 클래스 2개는 로컬 DB가 없어 생략했습니다. DB 검사는 별도 GitHub Backend DB integration에서 확인합니다. 브라우저 8개 파일의 178개 항목은 아래 보완 후 관련 파일·항목을 다시 검사해 통과했습니다. 최신 커밋의 CI 결과는 PR #79에 기록합니다.

- 큰 글씨에서 [안내 중단]으로 스크롤해도 고정 주문 바에 가리던 문제를 발견했습니다. 낮은 화면을 제외한 문서 스크롤에서 주문 바 높이를 버튼의 스크롤 여백에 반영했습니다. 음성 파일 전체 24개를 다시 실행해 통과했습니다.
- 이전 도움창 구조를 사용하던 음성 검사 7개를 새 창의 [닫기] 버튼에 맞췄습니다. 확장 통계 검사는 `VITE_TOUCH_INTERACTION_DRAFT=true`인 별도 서버에서 9개를 확인했습니다. 실제 특징 엔드포인트·기본 5개 필드·샘플 전송 차단 검사 3개도 생략 없이 통과했습니다. 특징 엔드포인트 검사의 내부 AI 분석 응답은 별도의 로컬 고정 HTTP 응답입니다. 확장 필드가 backend를 지나 AI에 전달되는지는 이 검사로 보장하지 않습니다.
- 동시 실행에서 250ms 연타 검사 1개가 추가 요청 2회로 실패했습니다. 기존 검사를 개별 실행한 4회에서는 재현되지 않았습니다. 검사에서 브라우저 시계를 제어해 입력 사이 앱의 시간이 정확히 250ms 지나도록 보완한 뒤 통과했습니다. 실제 장비의 연타 동작은 최종 확인이 필요합니다.

서버의 지원 응답은 현재 계약대로 `preset: none`입니다. 비모달 지원 바의 네 가지 제안·수락·거절·배치·다른 조작은 고정 HTTP 응답을 사용하는 `backendSupport.browser.test.mjs`와 지원 브라우저 검사에서 확인하며, 실제 AI 판단이 제안을 선택했다고 해석하지 않습니다. 실제 음성 설치·마이크·스피커 재유입·외부 AI·G10 검증은 남아 있습니다.
