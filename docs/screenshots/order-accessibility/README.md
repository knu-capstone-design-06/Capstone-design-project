# 주문 화면 접근성 개선 검증

2026-10-29 Windows Chrome headless에서 1080 × 1920 세로 뷰포트와 브라우저 배율 100%로 촬영했습니다. `frontend/src/features/order/accessibility.browser.test.mjs`가 고정 주문 API 응답을 주입한 화면입니다.

| 화면 | 설정과 확인 범위 |
|---|---|
| [기본 화면](menu-normal-100.png) | 기본 글자 크기, 메뉴·장바구니와 하단 고정 주문 바 |
| [200% 확대·고대비](menu-normal-200.png) | 큰 글씨·큰 버튼·고대비를 함께 적용한 상태 |
| [낮은 화면](menu-low-100.png) | 아래쪽 60%에 조작 영역을 배치한 상태 |
| [낮은 화면·200% 확대·고대비](menu-low-200.png) | 낮은 화면에 큰 글씨·큰 버튼·고대비를 함께 적용한 상태 |

확대·낮은 화면에서는 문서 또는 내부 영역을 스크롤해 상품·설정·옵션·주문 버튼에 접근합니다. 캡처는 스크롤 전의 첫 화면이며, 같은 브라우저 테스트에서 스크롤 후 상품 선택·옵션·담기·주문 확인 조작을 검사합니다.

테스트는 가로 넘침, 하단 주문 바의 예약 공간, 글자 확대와 일부 문자 대비를 확인합니다. 음성 합성·인식 검사는 모의 객체를 사용합니다. 실제 백엔드 저장, 마이크 인식 품질, 스피커 출력, 문자 높이(mm), 접근성 인증 결과를 검증한 기록은 아닙니다.

실제 G10에서는 Windows·브라우저 배율 100%, F11 전체 화면에서 터치 도달 범위·스크롤·음성 출력을 최종 확인해야 합니다. [개발·검증 기준](../../../frontend/README.md#키오스크-화면-개발-및-검증-기준)을 따릅니다.
