# 장바구니 총액 리뷰 반영 검증

2026-11-25 PR #102의 11월 24일 리뷰를 반영해 개발 PC의 Chromium headless에서 확인했습니다. 고정 API 응답을 사용한 로컬 브라우저 검사이며, GitHub CI나 실제 G10 검증 결과가 아닙니다.

총액 검사의 공통 단언은 실제 금액 글자의 경계를 재서 [닫기]·[주문 확인]과 겹치지 않고 장바구니 창의 상하좌우 범위 안에 있는지 확인합니다. 기본 배치에서도 [모두 보기]로 창을 열 수 있도록 아이스 19개·핫 1개 두 줄로 총액 70,000원을 구성했습니다. 각 조건에서 창 닫기와 주문 확인 화면 이동도 확인했습니다.

| 화면 조건 | 결과 |
|---|---|
| 1080×1920 기본 설정 | 통과 |
| 1080×1920 큰 글씨·큰 버튼·낮은 화면 | 통과, 창이 y=768~1920 안에 표시됨 |
| 1080×1920 크게 보기, 큰 글씨 끔 | 통과, `large-view` 갈래 확인 |
| 390×844 기본 설정 | 통과, 760px 이하 갈래 확인 |

새 검증 이미지:

- [크게 보기 1080×1920](large-view-1080x1920.png)
- [기본 설정 390×844](default-390x844.png)

기존 [큰 글씨·큰 버튼·낮은 화면 이미지](large-low-1080x1920.png)는 최초 PR에서 한 줄을 담아 확인한 기록입니다.

외부 Playwright와 Vite 서버를 준비한 뒤 `frontend/`에서 실행합니다. 환경변수 설정은 [주문 화면 검증 안내](../../../frontend/src/features/order/README.md#백엔드-없이-화면-검증)를 따릅니다.

```sh
node --test --test-name-pattern='기본·큰 글씨·크게 보기|옵션 창의 \[담기\]' src/features/order/order.browser.test.mjs
npm test
npm run build
```

총액 네 조건과 [담기] 연속 입력 세 조건이 통과했고, 단위 검사 일곱 파일과 TypeScript·Vite 빌드도 통과했습니다. 브라우저 검사는 로컬에서 별도로 실행했으며 현재 CI의 `pnpm test`·`pnpm build`에 포함되지 않습니다. Windows·브라우저 배율 100%·F11 전체 화면의 G10 최종 검증은 남아 있습니다.
