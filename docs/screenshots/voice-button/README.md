# 음성 모드 ON/OFF 버튼 미리보기

2026-10-15 사용자 요청으로 주문 화면에 추가한 버튼입니다. 현재는 ON/OFF 표시만 바뀌고 마이크 권한·음성 인식·음성 API는 호출하지 않습니다. 새로고침·새 세션에서 OFF로 시작하며 주문 완료 화면에서는 숨깁니다.

Chrome headless, CSS 픽셀·기기 배율 1·브라우저 확대율 100%에서 고정 주문 API 응답으로 촬영했습니다. 외부 웹폰트 요청은 차단해 시스템 대체 글꼴을 사용했습니다. 실제 백엔드·마이크·음성 해석과 G10의 F11·물리적 도달 범위를 검증한 자료는 아닙니다.

브라우저에서 클릭·Enter·Space 전환, `role="switch"`·`aria-checked`, ON/OFF 배경색 구분, 동작 줄이기 시 애니메이션 해제, 새로고침 후 OFF, 마이크 시작·추가 서버 요청 0회를 확인했습니다. 1080×1920·1920×1080·1365×768·390×844 × 기본·큰 글씨·큰 버튼·동시 적용 × 기본 높이·낮은 화면의 32개 조합에서 버튼의 화면 내 배치·중앙 가림·가로 넘침을 확인했습니다.

TypeScript 검사·Vite 빌드와 기존 `npm test`의 6개 테스트 파일도 통과했습니다. 기존 주문 브라우저 검사도 46개가 통과했습니다. 샘플·프로덕션 전용 2개 검사는 해당 실행 URL을 지정하지 않아 생략했습니다. 화면 미리보기용 모드 상태는 로컬 저장소에 보관하지 않습니다.

## 2026-10-16 접근성 리뷰 반영과 재검증

PR #47의 리뷰를 반영해 안내문 글자색을 `#45554d`로 바꾸고 위 대표 이미지 3개를 갱신했습니다. 화면 배경 `#f7f6f2`와의 대비는 약 7.30:1입니다. 버튼의 접근성 이름은 ‘음성 모드 미리보기’이며, 버튼 밖 안내문을 `aria-describedby`로 연결합니다. 켜짐·꺼짐은 `aria-checked`로 전달하고 버튼 내부의 별도 live region은 제거했습니다.

Windows의 Chrome 155.0.8059.79 headless에서 동일한 32개 화면·설정 조합의 대비(모두 약 7.30:1), 가로 넘침, 버튼·안내문의 화면 내 배치와 버튼 중앙 가림을 확인했습니다. 접근성 트리에서 이름·미리보기 설명·ON/OFF 상태를 확인하고 클릭·Enter·Space 전환, 동작 줄이기, 주문 확인 화면 유지·완료 화면 숨김, 새 세션·새로고침 OFF, 마이크 시작·버튼 조작에 따른 추가 서버 요청 0회를 확인했습니다. 촬영은 1080×1920·기기 배율 1·브라우저 확대율 100%, 고정 주문 API 응답과 시스템 대체 글꼴을 사용했습니다.

기존 의존성이 설치된 WSL의 Node.js 24.15.0에서 `npm test` 56개와 `npm run build`(TypeScript·Vite)가 통과했습니다. 접근성 트리 확인은 실제 스크린리더 음성 출력 검증을 대신하지 않습니다. NVDA·Windows 내레이터의 설명 전달·중복 낭독, G10의 F11·물리적 도달 범위, 실제 마이크·백엔드 연동은 미검증입니다.
