# 샘플 주문 화면

샘플 상품으로 메뉴 분류, 온도·수량 선택, 장바구니 수정·삭제, 주문 확인, 모의 결제와 주문번호 표시를 제공합니다. 실제 서버 주문·결제·음성·자동 지원 판단은 연결하지 않습니다.

큰 글씨, 큰 버튼, 간편 화면, 단계별 안내를 화면 도움 메뉴에서 직접 켜거나 끌 수 있습니다. 기본 화면 복귀는 접근성 설정만 초기화합니다.

장바구니와 접근성 설정은 현재 브라우저의 localStorage에 저장되어 화면 이동과 새로고침에도 유지됩니다. 모의 결제 완료 시 장바구니를 비우며 접근성 설정은 유지합니다. 같은 상품·온도는 수량을 합치고 최대 20개로 제한합니다. 모의 주문번호는 시연용 무작위 숫자입니다.

## 실행

Node.js 22.18 이상에서 `frontend/`를 작업 디렉터리로 사용합니다.

```sh
pnpm install
pnpm dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. 서버 없이 실행됩니다.

```sh
pnpm build
pnpm test
```

## 수동 확인

- 분류를 바꾸고 메뉴의 온도·수량을 선택해 담기
- 같은 옵션 합산과 다른 옵션 분리 확인
- 수량 변경·삭제 후 총액 확인
- 주문 확인에서 메뉴 선택으로 돌아가 장바구니 유지 확인
- 화면 도움 설정을 바꾼 뒤 새로고침해 주문과 설정 복원 확인
- 모의 결제 후 주문번호 표시와 새 주문의 빈 장바구니 확인
- 키보드 Tab·Enter로 주문하고 옵션 창 Escape 닫기 및 초점 복귀 확인
- 좁은 화면과 큰 글씨·큰 버튼 동시 적용에서 화면 확인

추후 주문 API 합의 후 이 기능의 상태 처리와 서버 연동을 연결합니다. 기존 `src/shared/api/`는 수정하지 않았습니다.
